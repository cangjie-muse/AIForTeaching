# 从零开始部署（小白版）

给完全没在 Linux 上装过东西的人。每一步都写四行：**做什么、敲什么、看到什么算成功、失败了怎么办**。

一次只粘一块命令，`看到什么` 对不上就停下来，把那一整屏复制给我。
不要跳步，也不要一次粘十条——中间某条失败了，后面的会连锁报错，反而更难判断。

> 已经有点 Linux 基础、想要更精简的版本：看 [服务器部署教程](服务器部署教程.md)。
> 想随时知道"现在到第几步"：`bash deploy/doctor.sh`（第 17 步会讲）。

---

## 0. 开始之前，准备好三样东西

1. **服务器的登录方式**：你已经能登进去（MobaXterm 窗口里出现 `aiformath@aiformath-PowerEdge-R720:~$`）。
2. **一个数据库口令**：现在想好，记在记事本里。
   规则：**≥12 位，字母 + 数字**，可以用 `-`。
   **不要用** `@ : / # ! $ % 空格`——这些符号在数据库连接串和命令行里有特殊含义，会让后面莫名报错。
   例子：`Whu2026jiangsan`
3. **半小时不被打断**：安装过程不需要一直盯着，但别中途关窗口。

## 1. 先认识这个黑窗口

| 你会看到 | 意思 |
| --- | --- |
| `aiformath@aiformath-PowerEdge-R720:~$` | 提示符。看到它 = 上一条命令跑完了，可以输下一条 |
| `[sudo] password for aiformath:` | 在问你**登录密码**。**打字时不显示任何字符**，这是正常的，输完按回车 |
| 什么都没发生 | 命令正在跑。装软件时可能几分钟没输出，别急 |
| `$` 后面还在 | 命令没跑完，或它在等你输入（比如 nano 编辑器） |

三个操作：

- **粘贴**：在窗口里点右键，或 `Shift + Insert`。不要用 `Ctrl+V`（在某些终端里是别的意思）。
- **中断**：`Ctrl + C`。命令卡住或你粘错了，按它就回到提示符。
- **关窗口**：`Ctrl + D` 或点关闭。注意：装到一半关掉，下次要重跑那一步。

还有一条：**提示符里的 `~` 就是 `/home/aiformath`**。下面所有 `cd` 都是相对这个目录。

## 2. 装系统软件

**做什么**：装 Python 运行环境、git（拿代码）、nginx（对外发网页）、PostgreSQL（数据库）和编译工具。

**敲什么**：

```bash
sudo apt update
sudo apt install -y python3-venv python3-pip python3-dev git curl ca-certificates unzip build-essential libpq-dev pkg-config nginx postgresql postgresql-contrib
```

**看到什么算成功**：最后几行是 `Setting up ...`，然后回到提示符，没有 `E: ` 开头的红字。

**失败了怎么办**：

- `Could not get lock /var/lib/dpkg/lock`：有别的 apt 在跑。等两分钟重试；还不行就 `sudo rm /var/lib/dpkg/lock-frontend` 后重试（这是安全操作）。
- 下载特别慢或 `Failed to fetch`：网络问题，重跑同一条命令；连续失败把输出贴我。
- `Unable to locate package`：`sudo apt update` 没跑成功，先跑它。

## 3. 装 PostgreSQL 的向量扩展（pgvector）

**做什么**：我们的 AI 问答要把文本变成向量存进数据库，这需要 pgvector。没有它，建表那一步就会失败。

**敲什么**：

```bash
PGVER=$(ls /usr/lib/postgresql | sort -V | tail -1)
echo "你的 PostgreSQL 版本：$PGVER"
sudo apt install -y "postgresql-${PGVER}-pgvector"
```

**看到什么算成功**：第二行打印出一个版本号（比如 `16`），最后一条**没有** `Unable to locate package`。

**失败了怎么办**（提示找不到包）：改用源码编译，一次粘完：

```bash
PGVER=$(ls /usr/lib/postgresql | sort -V | tail -1)
sudo apt install -y "postgresql-server-dev-${PGVER}" git make gcc
cd /tmp && rm -rf pgvector && git clone --branch v0.8.0 --depth 1 https://github.com/pgvector/pgvector.git
cd /tmp/pgvector && make && sudo make install
cd ~
```

最后一条 `make install` 成功时没有报错。若 `git clone` 卡住（访问不了 GitHub），把输出贴我，我给你换一条路。

## 4. 建数据库和账号

**做什么**：建一个数据库账号 `whu_math`、一个库 `whu_math_teaching`，并启用两个扩展。

**敲什么**（第一行会让你输入口令，屏幕上不显示，输完回车）：

```bash
read -rsp "给数据库定一个口令（就是第 0 步想好的那个）：" aiformath; echo

sudo -u postgres psql -c "CREATE ROLE whu_math LOGIN PASSWORD '$aiformath';"
sudo -u postgres psql -c "CREATE DATABASE whu_math_teaching OWNER whu_math ENCODING 'UTF8' TEMPLATE template0;"
sudo -u postgres psql -d whu_math_teaching -c "CREATE EXTENSION IF NOT EXISTS vector; CREATE EXTENSION IF NOT EXISTS pgcrypto;"
sudo -u postgres psql -d whu_math_teaching -c "ALTER DATABASE whu_math_teaching SET lc_collate = 'zh-x-icu';"
```

**看到什么算成功**：依次出现 `CREATE ROLE`、`CREATE DATABASE`、`CREATE EXTENSION`、`ALTER DATABASE`。

**失败了怎么办**：

- `role "whu" already exists` / `database "whu_teaching" already exists`：已经建过了，继续下一条即可。
- `permission denied to create extension`：`sudo -u postgres` 没用成。改用 `sudo -i -u postgres psql ...`，或把这一屏贴我。
- `peer authentication failed`：同上，用 `sudo -i -u postgres`。
- `invalid locale name: "zh-x-icu"`：系统没装 ICU 中文排序，跳过最后一条不影响功能（只是列表排序按字节）。

> 记一下：`$DBPASS` 这个变量只在**当前这个窗口**有效。后面如果关过窗口，需要重新 `export`（第 13 步会写进文件，就不用再记了）。

## 6. 装 Python 依赖

**做什么**：给这个项目建一个独立的 Python 环境（`.venv`），把依赖装进去。装在这台机器上，不影响系统自带的 Python。

**敲什么**：

```bash
cd /home/aiformath/AIForTeaching
python3 -m venv .venv
.venv/bin/pip install -U pip -i https://pypi.tuna.tsinghua.edu.cn/simple
.venv/bin/pip install -r server/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
.venv/bin/python -c "import fastapi, psycopg, pgvector; print('依赖 OK')"
```

**看到什么算成功**：最后一行打印 `依赖 OK`。

**失败了怎么办**：

- 第二条报 `No module named venv`：`sudo apt install -y python3-venv` 重跑第 2 步。
- 一直 `Downloading` 很慢：把 `-i https://pypi.tuna.tsinghua.edu.cn/simple` 去掉或换成别的镜像再试。
- `error: Microsoft Visual C++` 之类：那是 Windows 的错，说明你不在服务器上。先 `pwd` 确认。
- `Could not build wheels for psycopg`：说明没装 `libpq-dev`，回第 2 步。

## 8. 建表

**做什么**：把 17 个建表脚本按顺序执行，创建所有表和视图。

**敲什么**：

```bash
export DATABASE_URL="postgresql://whu_math:$aiformath@127.0.0.1:5432/whu_math_teaching"
.venv/bin/python db/migrate.py --apply
.venv/bin/python db/migrate.py --status
```

**看到什么算成功**：`--apply` 逐条打印 `0001 … 0017`；`--status` 里每一条都是「已应用」，没有「待应用」。

**失败了怎么办**：

- `NameError: DBPASS`：这个窗口里没有口令变量（关过窗口）。重新输一次：
  ```bash
  read -rsp "数据库口令：" DBPASS; echo
  export DATABASE_URL="postgresql://whu:$DBPASS@127.0.0.1:5432/whu_teaching"
  ```
- `type "vector" does not exist`：pgvector 没装成，回第 3 步。
- `password authentication failed`：口令不一致（建库时和这里用的不是同一个）。可以重置：
  ```bash
  sudo -u postgres psql -c "ALTER ROLE whu PASSWORD '$DBPASS';"
  ```
- **绝对不要**在服务器上加 `--pglite-compat`。那是给本机调试用的，会把向量列降级，等于把 AI 检索废掉。

## 12. 写配置文件

**做什么**：把连接数据库的口令、运行模式、允许访问的域名写进 `.env`。这个文件不进 git，权限设为只有自己能读。

**敲什么**（`PUT_PASSWORD_HERE` 会被替换成你的口令，注意口令里不要有 `|` 和 `&`）：

```bash
cd /home/aiformath/AIForTeaching
cat > .env <<'ENV'
DATABASE_URL=postgresql://whu_math:whu_math_teaching@127.0.0.1:5432/whu_math_teaching
APP_ENV=prod
AUTH_MODE=password
DEV_FAKE_MODEL=0
CORS_ORIGINS=http://115.156.72.1
UPLOAD_DIR=/home/aiformath/AIForTeaching/uploads
SECRETS_DIR=/home/aiformath/AIForTeaching/secrets
MAX_UPLOAD_MB=80
MODEL_EGRESS=allowlist
ENV

sed -i "s|whu_math_teaching|$aiformath|" .env
chmod 600 .env
mkdir -p uploads secrets && chmod 700 secrets
grep -c . .env        # 应该输出 9
```

**看到什么算成功**：最后输出 `9`；`ls -l .env` 显示 `-rw-------`。

**失败了怎么办**：如果 `DBPASS` 是空的（关过窗口），`sed` 会把口令替换成空，导致连不上库。
检查一下：`grep DATABASE_URL .env`，如果看到 `whu:@127.0.0.1` 中间是空的，重新输口令再 `sed` 一次。

> 还不知道域名？先用 IP（上面的 `CORS_ORIGINS`）。以后有域名了改这一行再重启服务。

## 13. 启动后端

**做什么**：交给 systemd 托管，让它开机自启、崩了自动重启。这台机器上它只监听 `127.0.0.1:8000`，外网进不来，前面由 nginx 转发。

**敲什么**：

```bash
sudo cp deploy/whu-teaching.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now whu-teaching
sleep 3
systemctl status whu-teaching --no-pager | head -12
curl -s http://127.0.0.1:8000/api/v1/health
```

**看到什么算成功**：

- 状态里有一行 `Active: active (running)`
- `curl` 返回类似 `{"status":"ok","db":true,"courses":14,...}`

**失败了怎么办**：

```bash
sudo journalctl -u whu-teaching -n 50 --no-pager
```

- `connection failed` / `password authentication failed`：第 12 步的 `.env` 里口令不对。
- `No such file or directory: 'app.main'`：单元文件里的 `WorkingDirectory` 被改过，应指向 `…/server`。
- `can't open file`：`EnvironmentFile` 路径不对（应为 `/home/aiformath/AIForTeaching/.env`）。

## 14. 启动前端（nginx）

**做什么**：让 nginx 把 `index.html` 和静态文件发出去，并把 `/api/` 转给后端。

> 为什么前端要 nginx 发：代码里 `APP_ENV=prod` 时后端**故意不托管前端**，避免把 `secrets/`、`db/`、
> 后端源码暴露出去。所以打开首页是 404、接口却正常，就是这一步没做。

**敲什么**：

```bash
cd /home/aiformath/AIForTeaching
sudo cp deploy/nginx.conf.example /etc/nginx/sites-available/whu-teaching
sudo sed -i 's/math.example.edu.cn/_/' /etc/nginx/sites-available/whu-teaching
sudo ln -sf /etc/nginx/sites-available/whu-teaching /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
curl -sI http://127.0.0.1/ | head -3
```

**看到什么算成功**：`nginx -t` 输出 `syntax is ok` 和 `test is successful`；`curl` 第一行是 `HTTP/1.1 200 OK`。

**失败了怎么办**：

- `nginx: [emerg] unknown directive`：配置里有多余字符，重新 `cp` 一次再 `sed`。
- `curl` 返回 403/404：`ls index.html` 确认文件在，且 nginx 配置里 `root` 指向 `/home/aiformath/AIForTeaching`。
- 拒绝访问：防火墙。`sudo ufw status`，如果开着就 `sudo ufw allow 80,443/tcp`。

## 18. 常见错误速查

| 现象 | 多半是 | 怎么办 |
| --- | --- | --- |
| 首页 404，`/api/v1/health` 正常 | nginx 没托管前端 | 第 14 步 |
| 网页打开了，但没有课程 | 数据没导入 | 第 9 步 |
| 登录成功，一刷新就掉线 | nginx 少了 `X-Forwarded-Proto` | 重新 `cp deploy/nginx.conf.example`，别手改 |
| 上传教材报 413 | nginx 上传上限太小 | 配置里 `client_max_body_size 300m;` |
| 问答一直「没有知识片段」 | 语料没生成 | 第 11 步 |
| 问答 502 | 模型 Key 没填/填错 | 第 16 步 |
| 某个页面 500，日志里 `UndefinedColumn` | 代码比数据库新 | `.venv/bin/python db/migrate.py --apply` |
| `sudo` 提示输密码但打不出字 | 正常，密码不回显 | 输完直接回车 |
| 换了文件，网页没变化 | 浏览器缓存 | `Ctrl + F5` 强制刷新 |

## 19. 以后怎么办

**更新代码**（我这边有新版本时）：

```bash
cd /home/aiformath/AIForTeaching

bash deploy/update.sh             # 拉代码 → 装依赖 → 迁移 → 重启 → 自检
```

**每天自动备份数据库**：

```bash
bash deploy/backup.sh             # 先手动跑一次，确认输出 ✓
crontab -e                        # 在打开的文件末尾加一行，保存退出：
# 20 3 * * * cd /home/aiformath/AIForTeaching && bash deploy/backup.sh >> ~/backup/backup.log 2>&1
```

**改东西**：改课程内容用网页里的「课程内容工作台」；改前端/接口/表结构分别改哪个文件，
见 [服务器部署教程 第 10 节](服务器部署教程.md)。

**服务在哪、怎么看日志**：

```bash
systemctl status whu-teaching          # 是否在跑
sudo journalctl -u whu-teaching -f     # 实时日志，Ctrl+C 退出
sudo systemctl restart whu-teaching    # 重启
```
