日期：2026-10-09。版本：v0.2。对象：智慧武大数学课程平台本地展示包。

## 结论与范围

本次检查未发现来自雨课堂的页面代码、样式文件、SDK、接口地址、品牌标识或静态资源。结合本对话的创建记录，网站页面与业务交互是在本项目中独立编写的（AI 辅助），公开产品资料用于了解教学需求，没有作为页面源码或模板导入。

这是一份项目来源审计：检查文件、构建路径、组件发布包、实际加载入口和运行结果。未获取雨课堂登录后完整源码，也未使用全网代码相似性数据库。因此不把“未发现相关来源”表述成“任意片段与所有网站都零相似”，不把关键词扫描当作单独的原创性证明。

整个分发包不能称为全部原创，因为其中有通用开源组件、校园摄影和用户提供的教材。它们与项目页面代码分开登记，原作者与许可、教材出处予以保留。

本次保留全部原作者署名、许可证和教材引用。来源独立性的判断结合创建记录、公开依赖核验和文件清单，不单凭代码外观或关键词得出。

## 可复核入口

- `config/vendor-assets.json`：第三方分发文件映射。
- `reports/dependency-origin.json`：npm 发布包完整性及每个分发文件的摘要。
- `reports/source-provenance.json`：项目源码、教师资料和生成数据的文件清单与 SHA-256。
- `scripts/verify-dependency-origin.cjs`：读取 npm tarball，先验证 SHA-512，再比较分发文件。
- `scripts/audit-source.cjs`：重新核对项目清单、加载来源、组件完整性和当前离线基线。

`npm run audit:sources` 不需要联网。升级依赖时，应先从对应 npm 版本的发布包更新依赖核验记录。未来接入自己的后台服务后，需要相应调整离线网络检查基线，不能把当前的“未联网”状态当作永久产品限制。
