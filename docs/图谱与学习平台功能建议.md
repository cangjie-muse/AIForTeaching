# 知识图谱与学习平台功能建议

日期：2026-10-10。依据：用户的36门课程建设计划、现有本地平台和代表性产品的官方公开资料。

2026-10-11 补充：网站现已接入 10 门课程；下面早期提到“只有辛几何与数学物理已接入”和“下一门课程”的表述是 v0.3—v0.5 阶段记录，当前接入数及来源问题以 [课程接入清单](课程接入清单.md) 为准。

v0.7 已落实建设期专用的信息汇总：逐门课程资源统计、两期接入情况与待核对数据均来自实际课程包。负责人、计划日期和教师审核结果尚无标准数据，暂不展示虚构值。

## 用户确认与 v0.4 修订

用户确认课程大纲和知识图谱应保持两个独立入口，课程导入仍在现有位置；账号、服务器共享存储、审核发布与版本管理留待以后。以下较早的建议以本节确认的决定为准。

v0.4 建立三级入口：全课程知识点、全课程概览（章节）、单章关系图。其全课程列表显示全部知识点名称；章节图将完整名称放进可点击卡片，名称过长换行，而不是只在悬停时出现。知识点顶部的关联题数量可点；导入增加可编辑课程名称，确认后自动生成课程、图谱与题库。

v0.5 再按用户反馈将“全课程知识点”改为**图谱默认、表格可切换**。总图 259 节点先整体适配画布，再放大查看局部名称；表格承担逐条阅读。章节图谱也改为圆形分层布局，打开时按节点实际边界自动适配。此处“100%”指适配比例，不是 SVG 原始像素比例。[Kumu 的网络图建议](https://docs.kumu.io/disciplines/sna-network-mapping)提醒密集网络应分层聚焦，[Cytoscape.js 的视口文档](https://js.cytoscape.org/)给出按节点范围 fit 和 padding 的思路；这些只是设计依据，代码与视觉样式均为本项目重写。

## 本轮已经落地

- 将目录扩充为36门课程，按用户顺序列出。前10门为“基础课程（一期核心课程）”，后26门为“专业课程（二期重点课程）”。数学分析I、II、III分别建项。一期截止概率论，实变函数起进入二期。
- 全部课程页面分两块展示，保留并强化“已接入”筛选。当前只有辛几何与数学物理接入正式资源包，其余35门是可进入的课程框架。
- 知识图谱改为本项目独立实现的节点—连线网络，提供课程概览、章节展开、搜索定位、拖动画布和节点、缩放、关联聚焦和节点详情。
- 两种连线分开：章节归属来自现有层级；共用习题来自题库的多知识点关联。全课程可计算出55对共题知识点，“辛流形”章内有11对。点击共题连线可以查看原题作为依据。
- 未把共题关系解释成先修、逻辑推导或定理依赖；这些关系需另有教师确认的数据。

## 调研发现与设计判断

本次研究代表性产品，没有声称穷尽所有平台，也没有复制它们的页面代码、样式或图形资源。

| 参考产品 | 从官方资料确认的设计 | 对本项目的启发 |
| --- | --- | --- |
| [Obsidian Graph view](https://obsidian.md/help/plugins/graph) | 全局与局部关系图、悬停突出连线、缩放拖动、筛选与分组 | 用网络探索关系，同时保留课程大纲；节点多时逐层展开 |
| [Kumu Focus](https://docs.kumu.io/guides/focus) | 围绕选定节点聚焦，按连接层数扩展视野 | 演示时聚焦少量相关概念，提供明确的退出聚焦入口 |
| [Kumu Fields](https://docs.kumu.io/guides/fields) 与 [Cytoscape.js 样式文档](https://js.cytoscape.org/) | 节点以文字标签识别；长标签可按宽度换行或省略 | 本课程图谱优先显示完整名称，并让布局为标签留空间；这是本项目的设计判断 |
| [Moodle 题库](https://docs.moodle.org/502/en/Question_bank) | 题库复用、分类、版本，以及 Draft/Ready 状态 | 题目按稳定ID维护，发布前审核，教学任务可锁定版本 |
| [OpenStax Assignable](https://help.openstax.org/s/article/What-is-OpenStax-Assignable) | 将教材阅读与对应章节的练习组织为学习任务 | 把知识阅读、习题与反馈串起来，避免各模块相互孤立 |
| [Hypothesis 教育方案](https://web.hypothes.is/education/) | 在阅读内容上高亮、注释并交流 | 讨论挂在具体知识点或证明段落，便于定位疑问和纠错 |
| [Khan Academy Mastery](https://support.khanacademy.org/hc/en-us/articles/115002552631-What-are-Course-and-Unit-Mastery) | 按技能与单元记录练习表现，并推荐后续学习 | 建立复习队列，但本项目需区分“读过”“自评”“作答证据”，尤其不能自动把证明题自评当成绩 |

上述“启发”列是结合本项目作出的建议，不表示这些平台的做法适合原样照搬。

## 图谱应该怎样继续完善

1. **分三个尺度。** 全课程知识点总图显示全部节点，课程概览显示章节，进入章节查看知识点；选择知识点后聚焦它的邻居。跨课程总图留到多门课程有实际内容之后。
2. **每条边能够解释。** 保留章节归属、共题关系，后续再加入先修、推导、例子和应用。学术关系最好带依据、来源和审核状态。
3. **节点详情承担阅读。** 图中直接显示完整名称，正文、公式、证明、例子、题目和来源在详情中展开。
4. **名称默认可见。** 长名称换行、图形按层级展开；搜索、键盘选择和课程大纲能找到同一个知识点。
5. **阅读不依赖图形。** 课程大纲与网络图是同一套内容的两种入口；顺序学习、移动端和辅助技术仍需要列表。

现有文件能够可靠支持前述层级与共题关系，无须重新分析教材。真正的先修/推导关系可通过可选关系文件补充，保持三份标准输入继续可用。

## 建议新增：按阶段排序

### 先服务学院展示

- **五分钟演示路线。** 从36门课程布局进入已接入示范课，再展示图谱、知识正文、一题多知识点及带出处的问答入口。导航可收起无关部分，演示数据要与建设数据明确对应。
- **建设进度清单。** 对每门课记录负责人、资源包版本、知识点/题库接入与审核状态。没有内容的课程显示待建设，不填虚假的完成率。

### 转入实际教学时再评估

| 优先级 | 建议 | 具体作用 |
| --- | --- | --- |
| 后续 | 教师/学生身份、课程权限、服务器共享存储 | 老师上传后，指定学生才能看到同一份已发布内容；用户已决定暂缓 |
| 后续 | 导入→预览校验→教师审核→发布→版本历史 | 避免更新讲义后，同一作业的题目和答案发生无记录变化；用户已决定暂缓 |
| 高 | 知识点及题目级讨论、纠错 | 学生指出具体步骤；教师确认后修订，保留修订依据 |
| 高 | 复习清单与继续学习 | 将已有收藏、笔记、已读、作答、自评组织起来；优先回看待巩固内容 |
| 高 | 搜索升级 | 在现有标题与关键词搜索基础上，逐步支持正文、中英文术语、来源页码和公式友好检索 |
| 中 | 情境化AI提示 | 在当前知识点/题目旁展开问答，先提示再解答，附可点击来源及教师纠错入口 |

### 内容丰富后再做

- **数学交互实验。** 例如Hamilton相图、向量场、曲面、随机过程或数值迭代，让学生改变参数并观察；与具体知识点和习题关联。
- **跨课程知识联系。** 例如流形、线性算子等在不同课程中的联系。由教师确认是否指向同一概念，保留各课程的记号、条件和叙述，不仅凭同名就合并。
- **教学班学情分析。** 等真实学习和作答数据接入后定义指标，分清阅读行为、学生自评与教师评价。

## 现有入口的取舍

| 现有位置 | 建议组织方式 | 理由 |
| --- | --- | --- |
| 课程大纲＋知识图谱 | 保持两个独立入口 | 用户确认两个功能各有用途 |
| 课程导入 | 保持现有导航位置，新增课程名称与自动生成说明 | 用户确认暂时不调整菜单位置 |
| 我的学习＋分散的个人练习记录 | 合并为“学习档案”：继续学习、收藏、笔记、作答、待巩固 | 当前个人记录已有基础，缺的是统一回看与复习流程 |
| 建设与学习分析 | 建设概览放展示/管理端，个人学习记录放学生端，班级统计放教师端 | 三者面向不同对象，指标不应混用 |
| 独立AI页面＋带题目跳页提问 | 保留情境问答，优先改为原页面侧栏；需要长对话时再展开 | 现有上下文传递已经可用，侧栏能减少阅读与问答间来回跳转 |
| 全局图谱、习题和AI入口默认进入第一门已接入课 | 进入前明确选择课程，或只在课程内部展示这些入口 | 36门课之后，默认跳到第一门课容易让人误解 |

建议暂缓自建直播系统、位置签到、排行榜及证明题自动评分。当前“课堂互动”等规划模块可以保留在教师工作台，不必为了展示而优先实现。尚无数据的班级统计和空讨论区，正式学生界面中可按开放状态显示。

本轮落实课程名称导入、知识点与习题双向跳转，以及更清晰的全课程与章节图谱；其他建议尚未实施。
