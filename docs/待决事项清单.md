更新方式：每定一项就改状态，并记到文末的决定记录表。

状态：`待定` / `已定` / `暂缓`

## A. 必须你或学院拍板（不定就会返工）

### A1. 部署在哪里

| 选项 | 好处 | 代价 |
| --- | --- | --- |
| 学院自建服务器 | 数据不出校，可控 | 要有人运维；没有 GPU 就跑不了本地大模型 |
| 学校统一云/信息中心 | 合规最省事，有备份 | 审批流程长，资源申请要排队 |
| 公有云（阿里云/腾讯云） | 开通快，弹性 | 数据出境需报备，长期费用 |

**为什么必须你定**：直接决定有没有 GPU、数据能不能出校、谁来负责运维。
**不定会怎样**：部署方案推翻重来，前面写的配置全部作废。
**建议期限**：两周内。
**我的建议**：一期放学院自建服务器，只用 API 调模型（不需要 GPU）；等问答跑通、有真实使用量后再考虑本地模型。

### A2. 数据能不能出校园网

具体是三个问题，答案可能不一样：

1. 教材 PDF 与切片，能不能传给 DeepSeek / 阿里云？
2. 学生提问内容，能不能出校？
3. 学生对话记录，能不能存在第三方？

**为什么必须你定**：能出校 → 用 API，成本低、效果好；不能出校 → 必须本地部署模型，要显卡、要运维。
**不定会怎样**：技术选型整个反转。
**建议**：教材正文和题干可以出校（本来就是公开教材），**学生身份与对话记录不出校**——这条最稳妥，也最容易通过审批。

### A3. 一期做哪几本教材

需要你给出清单，每本标注：书名、版次、作者、有没有电子版 PDF、是扫描件还是文字版、版权状态。

**为什么必须你定**：直接决定切片工作量。文字版一本约两周，扫描件（要 OCR + 公式校对）约两个月。
**不定会怎样**：做到一半发现教材是扫描件，工期翻倍。
**建议**：一期只做**数学分析 I**，且优先选有文字层的版本。做完一本再复制经验。

### A4. 身份认证怎么做

| 选项 | 说明 |
| --- | --- |
| 接学校统一身份认证（CAS / OAuth2） | 学生不用另设密码，最正规；要与信息中心对接 |
| 先做本地账号 | 自己能做主，但学生要单独注册，且无法与教务数据打通 |

**为什么必须你定**：不接统一认证，学生身份就是"用户自己说了算"，成绩、作业、学伴记忆都不可信。
**不定会怎样**：用本地账号上线，后面换统一认证要迁移所有账号与数据。
**建议期限**：**现在就去问信息中心**。流程比代码慢得多，这是整个项目最长的前置依赖。
**我的建议**：一期用统一认证；如果流程走不完，先用"教师账号 + 临时学生码"过渡，但数据结构必须按统一认证设计（现在已经是）。

### A5. 问答的教学口径

三个具体问题，只有教师能定：

1. **学生问作业题，AI 该直接给答案，还是只给提示？**
2. **作业期间要不要禁用 AI 学伴？**
3. **学生问"我算的对不对"，允许它指出错误，还是只给判断不给过程？**

**为什么必须你定**：这是教学法与学术诚信问题，不是技术问题。做错了学生会骂，教师会反对。
**不定会怎样**：上线后被教师质疑"鼓励抄作业"，整个项目停摆。
**建议**：默认**给提示不给完整答案**，作业截止前 72 小时对已发布作业禁用问答；这两个开关做成配置项，教师可按课程调整。

## B. 我已按默认值推进，你不反对就保持

以下都已落进代码与文档，改起来不难，但改了要动数据：

| 事项 | 当前默认 | 影响 |
| --- | --- | --- |
| embedding 模型与维度 | BGE-M3 / 1024 维 | 改了要全库重算向量 |
| 主键形式 | 复合 `(course_id, id)` | 现有 508/614 处跨课程重名，不改无法入库 |
| 章节建模 | 提升为 `chapter` 表 | 改回去要重写查询 |
| 可信等级 | 三档 + 人工/Lean 两维 | 与"三个层次"的表述一致 |
| 审核发布闸门 | 人工审核 + 已发布 + 许可 | 决定学生能看到什么 |
| 数据库变更方式 | 迁移制，已应用文件不可改 | 改成手改 schema 会有丢数据风险 |
| 中英术语表 | 人工维护，不用机器翻译 | 术语错会直接损害可信度 |

## C. 需要你提供的东西（不是决定，是输入）

1. **教材清单与文件**（见 A3）
2. **每门课的审核人名单** —— 谁能终审？谁只能改挂载？
3. **50 个真实学生问题** —— 取自往年答疑、作业错误、考试高频疑问。这是评测集的起点，事后补不出来。
4. **200 个中英数学术语** —— 建议从数学分析开始，教研室一起过一遍。
