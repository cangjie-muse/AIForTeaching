# 智慧武大 · 数学课程平台

本地展示版 v0.11，2026-10-11。用于向学院展示数学智慧课程的建设效果。

当前已接入 **14 门课程**：新增复变函数、数学分析 I/II/III，共 4146 个知识点、4807 道各课内按 ID 去重的习题、5287 条关联。四门新课的三份标准文件和 85 张实际引用插图来自知识数据库交付包，来源目录未改。**同调论尚未接入**：同事的三件套含题目，但缺网站必需的稳定题目 ID，难度/出处格式也不兼容；可交给来源维护智能体的[修订提示词](docs/同调论资源包修订提示词.md)已备好。详情见[课程接入清单](docs/课程接入清单.md)。

知识图谱现在会在画布下方汇总**当前节点及全部下级**：显示末端知识点数和按源题 ID 去重的关联习题数。点“展开知识点与习题清单”，左列可逐项打开知识正文，右列以“习题 1、习题 2……”显示完整题干与公式；点击题目任意位置进入单题作答页，再按需展开参考简解与来源。小范围卡片高度随题干变化；全课程题量很大时，右列在固定视区内滚动。母节点与子节点原有的层级跳转保持不变。

## 打开网站

**看真实数据（推荐，审核与可见范围只有这种模式生效）**

```bash
npm run dev:api      # 起后端 + 数据库，然后打开 http://127.0.0.1:8000
```

页面启动时从数据库读课程目录和正文：库里的课程已发布才对学生可见，审核、可见范围、改库发布都在这一条链上生效。
机制和迁移步骤见[数据来源与课程导入](docs/数据来源与课程导入.md)。

**离线演示（不需要后端）**

双击本文件夹中的 **index.html**，用浏览器打开即可。核心功能不需要联网或安装软件。此时页面用的是打包在 `data/courses.js` 里的静态内容，顶栏会标「离线演示数据」——审核与可见范围在这种模式下不生效，这是有意的：连不上库就不该假装在读库。请保留整个文件夹，不要只复制 HTML；数学公式字体、课程数据与必要插图在旁边的子目录中。

也可以在本机双击 **启动本地网站.command**，以已验证的 HTTP 方式访问。它使用本机现有 Python 3，在固定本地地址 http://127.0.0.1:8765 打开网页；保持固定地址有利于恢复浏览器中的课程和学习记录。展示时保留终端窗口，结束时按 Ctrl+C。

自动化验证覆盖了本地 HTTP 方式。浏览器工具禁止 `file://` 协议，因此未直接验证双击 HTML 的运行结果。

如需发给同事，使用 `智慧武大数学平台-本地展示版.zip`，完整解压后打开 index.html。

## 建议的展示顺序

1. 课程中心：查看两期 36 门规划课程，点击“已接入”查看 14 门已有实质内容的课程。
2. 进入“辛几何与数学物理”，打开知识图谱：先看默认的全课程关系图，放大局部或切换“表格”逐条阅读；再切到全课程概览与“第8章 辛流形”。单章节点直接显示名称，点击共题虚线可查看原题依据。
3. 点击“辛流形的定义”，阅读数学内容；点顶部“2 道关联习题”直达对应题目，也可收藏或写笔记。
4. 进入题库，按章节和难度筛选，展开参考简解，也可保存个人作答。
5. 从知识点或习题进入 AI 助手。当前提供明确标注的本地资料检索，生成式模型尚未接入。
6. 查看教学工作台中的作业、测验考试、课堂互动、讨论、公告和班级页面。可以创建、编辑和导出本地教学草稿。
7. 打开“信息汇总(仅建设过程用) → 建设进度汇总”，查看两期资源接入、逐门知识点与习题数，以及待核对事项。此页适合学院建设阶段汇报。
8. 打开“教学与建设 → 课件生成与修改”，看辛几何第一章 V1—V5 的逐页预览、教师修订建议和每次修改；可下载真实 PPTX。其它章节显示“未生成”，点击生成按钮可看未来 AI 请求内容。
9. 进入课程导入，演示标准文件的检查与接入流程。“建设与学习分析”仍保留课程与本机个人记录视角。

## 添加或更新课程

在“课程导入”中填写课程名称并选择资源包文件夹，根目录须有 `知识节点.xlsx`、`知识点.md`、`习题.md`。正文或习题引用了插图时，还需选择相应图片并保持相对路径；PDF 教材不是网站导入必需品，也不会复制到离线包。名称留空时，选择文件后自动带入资源包中的课程名称，确认前可修改。平台先自动解析知识节点、正文与习题并显示检查结果；确认后，课程入口、图谱和题库立即可用，无须逐项创建。匹配现有 36 门规划课时点亮原卡片；新课程会增加在“新导入课程（待归类）”区域。同一课程 ID 更新内容，不清空按 ID 保存的学习记录。

导入结果、三份标准文件和引用插图会存入当前浏览器的 IndexedDB；失败时会明确提示仅当前会话可用。换电脑或浏览器时，重新导入原资源包。浏览器数据不是文件备份。通过界面导入的课程不自动写回本网站文件夹；需要制作可转发的新版展示包时，使用下面的开发导入命令。

学习记录、笔记和教学草稿保存在本机。学习记录与教学草稿分别提供导出；学习记录可以重新导入。文件协议下的浏览器存储支持可能有差异，换电脑前请导出记录。

## 维护入口

开发环境需要 Node.js；普通浏览不需要。

```sh
npm install --ignore-scripts
npm run prepare:assets
npm run import:course -- "/完整路径/另一门课-课程资源包"
npm run check
```

`npm run import:course` 会生成离线数据、复制资源，且保留其他已经导入的课程。源资源包只读。

可选的 HTTP 预览：`python3 scripts/serve.py`，访问 http://127.0.0.1:8765。服务器只监听本机，退出时 Ctrl+C。双击 index.html 不依赖这个服务器。


## 代码位置

- `js/import-core.js`：浏览器与命令行共用的资源包解析和验证。

- `js/course-catalog.js`、`js/catalog-view.js`：36 门课程的规划目录与筛选界面。
- `js/construction-model.js`、`js/construction-view.js`、`styles/construction.css`：建设期汇总指标与展示页面。
- `js/courseware-view.js`、`styles/courseware.css`、`data/courseware.js`：章节课件、版本与反馈界面；`courseware/` 存放真实课件和预览。
- `js/graph-model.js`、`js/graph-atlas.js`、`js/graph-view.js`、`js/graph-interaction.js`：总图和章节关系图的数据、绘制与交互。
- `js/visual-identity.js`、`js/course-cover-art.js`、`styles/identity.css`：本项目编写的 SVG 图标、逐门课程封面和研习导览。
- `js/pages.js`、`js/learning.js`、`js/workspace.js`：页面与交互。
- `js/import-ui.js`、`js/storage.js`：导入预览与浏览器持久化。

## 来源检查

`npm run audit:sources` 重新核对项目源文件、页面入口、离线加载基线、组件哈希及资料清单。`npm run check` 同时运行这些检查。

`config/vendor-assets.json` 是分发组件的唯一映射清单。组件升级时，从 npm 取得对应版本发布包，再运行 `node scripts/verify-dependency-origin.cjs /发布包目录` 更新核验记录。来源扫描不等于全网代码相似性判定。将来接入本项目后台时，需同步调整当前离线版本的网络检查基线。
