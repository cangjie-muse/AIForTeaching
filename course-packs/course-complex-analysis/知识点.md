#### 复数

**图谱路径：** 复变函数 / 复数和复函数 / 复数域 / 复数

**教材范围：** 谭小江、伍胜健《复变函数简明教程》（北京大学出版社，2005），第一章§1.1，书页1–7，PDF页13–19；同事图谱节点

#### Euler公式

**图谱路径：** 复变函数 / 复数和复函数 / 复数域 / Euler公式

#### 收敛序列

#### 解析函数

#### Cauchy积分定理

#### Cauchy积分公式

**图谱路径：** 复变函数 / Cauchy定理和Cauchy公式 / Cauchy公式 / Cauchy积分公式

**教材范围：** 谭小江、伍胜健《复变函数简明教程》（北京大学出版社，2005），第三章§3.3，书页86–93，PDF页98–105；同事图谱节点

**习题：** [题目与简解](习题.md#ca-cauchy-formula)

**知识内容。** 若 $f$ 在包含闭圆盘的邻域解析，$z$ 位于其正向圆周 $\gamma$ 内，则 $f(z)=\frac1{2\pi i}\oint_\gamma f(\zeta)/(\zeta-z)\,d\zeta$；逐次求导得 $f^{(n)}(z)=\frac{n!}{2\pi i}\oint_\gamma f(\zeta)/(\zeta-z)^{n+1}\,d\zeta$。

**知识内容。** 复幂级数 $\sum_{n\ge0}a_n(z-z_0)^n$ 有收敛半径 $R\in[0,\infty]$；在 $|z-z_0|<R$ 的紧子集上一致收敛，可逐项求导积分，且所得和在圆内解析。解析函数反过来局部等于其 Taylor 级数。
