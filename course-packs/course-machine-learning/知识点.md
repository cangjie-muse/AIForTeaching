**知识内容。** 有标记数据$(x,y)$的分类预测离散类别，回归预测数值；聚类按相似关系划分无标记样本。任务类型决定输出、损失与评价，不能用类别编号的数值距离代替分类意义。

### 监督与无监督学习

**知识内容。** 监督学习利用样本标记，非监督学习不依赖已有类别标记；半监督还使用未标记样本。训练可用信息范围应明确，测试标签不得进入模型拟合。

### 归纳学习与演绎

**知识内容。** 从例子得到一般规律属归纳，从规则推出个例属演绎。有限数据通常与多种规律一致，因此归纳需函数族和偏好。教材通过西瓜分类候选合取式说明。

### 假设空间

**图谱路径：** 机器学习 / 第1章 绪论 / 假设空间

**教材范围：** A：周志华《机器学习》，清华大学出版社，2016年第一版，ISBN9787302423287，§1.3，书页4—6（PDF第19—21页）。

**习题：** [题目与简解](习题.md#kp-a-ch01-hypothesis)

**知识内容。** 假设空间$\mathcal H$是允许的候选模型集合。离散合取式可指定属性值或通配符，另有恒假假设。搜索空间的表示能力、规模和训练约束共同影响学习。

<a id="kp-a-ch01-version"></a>
### 版本空间

**图谱路径：** 机器学习 / 第1章 绪论 / 版本空间

**教材范围：** A：周志华《机器学习》，清华大学出版社，2016年第一版，ISBN9787302423287，§1.3，书页5—7（PDF第20—22页）。

**习题：** [题目与简解](习题.md#kp-a-ch01-version)

**知识内容。** 版本空间$\mathcal V(D)=\{h\in\mathcal H:h(x_i)=y_i,\ \forall i\}$包含全部与训练一致假设。新样本可排除不一致项；噪声可使空间为空。版本空间不是学习算法唯一输出。

<a id="kp-a-ch01-conjunction"></a>
### 合取式与析合范式

**图谱路径：** 机器学习 / 第1章 绪论 / 合取式与析合范式

**教材范围：** A：周志华《机器学习》，清华大学出版社，2016年第一版，ISBN9787302423287，§1.3、习题1.2，书页4—7（PDF第19—22页）。

**习题：** [题目与简解](习题.md#kp-a-ch01-conjunction)

**知识内容。** 合取式要求全部属性条件同时满足，析合范式把多个合取式作或，可表达不同正例区域。语法表达可能因冗余等价，同一真值函数不应重复计成不同语义假设。

<a id="kp-a-ch01-bias"></a>
### 归纳偏好

**图谱路径：** 机器学习 / 第1章 绪论 / 归纳偏好

**教材范围：** A：周志华《机器学习》，清华大学出版社，2016年第一版，ISBN9787302423287，§1.4，书页7—8（PDF第22—23页）。

**习题：** [题目与简解](习题.md#kp-a-ch01-bias)

**知识内容。** 有限训练一致假设可对新样本不同，算法用偏好选择。偏好可依模型简单性、距离、先验或任务知识。噪声情形可在经验损失和复杂度间折中，不再只要求训练完全一致。

**知识内容。** 过拟合捕获训练样本偶然细节，欠拟合遗漏任务规律。二者由函数族、数据和训练共同决定。训练误差小而测试较大提示过拟合，训练和测试都大还需区分模型偏差与优化未充分。

**知识内容。** $P=TP/(TP+FP)$，$R=TP/(TP+FN)$。改变阈值常有权衡；分母0需明确处理约定。P依类先验，R等于真正例率。

**主题导读。** Bagging 对自助抽样数据训练多个模型并汇总，主要降低方差；随机森林再随机选择候选特征。Boosting 顺序强调先前难分样本，形成加权组合。集成效果还依赖个体学习器的误差与多样性，不能只靠增加模型个数。

### 独立投票的误差界

### AdaBoost权重更新

**图谱路径：** 机器学习 / 第8章 集成学习 / AdaBoost权重更新

**知识内容。** 误差$\epsilon_t$下$\alpha_t=\frac12\log((1-\epsilon_t)/\epsilon_t)$，$D_{t+1}(i)\propto D_t(i)e^{-\alpha_ty_ih_t(x_i)}$。$\epsilon_t=0$或不小于1/2需相应停机/处理，不能直接取无限或非正权。

### 指数损失与分类

**图谱路径：** 机器学习 / 第8章 集成学习 / 指数损失与分类

**教材范围：** A：周志华《机器学习》，清华大学出版社，2016年第一版，ISBN9787302423287，§8.2，书页174—176（PDF第189—191页）。

**习题：** [题目与简解](习题.md#kp-a-ch08-exponential)

**知识内容。** 指数风险条件期望$p e^{-f}+(1-p)e^f$的最优$f=\frac12\log(p/(1-p))$，符号对应最大后验类别。结论依可选函数及边界处理，不是任意单调函数都自动给相同最优风险。

### 可实现与不可实现情形

### 有限假设的可实现样本界

**知识内容。** 一致学习器若$|\mathcal H|<\infty$，坏假设仍一致概率至多$e^{-m\epsilon}$，并合界得$m\ge(\log|\mathcal H|+\log(1/\delta))/\epsilon$。假设固定且样本独立。

<a id="kp-a-ch12-uniform-convergence"></a>
### 有限空间一致收敛

**知识内容。** Hoeffding加并合界给$\sup_h|\hat R(h)-R(h)|$控制，规模约$\sqrt{(\log|\mathcal H|+\log(1/\delta))/m}$。经验风险最小化风险与最优之差再加两倍一致偏差。
