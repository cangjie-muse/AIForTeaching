#### 原函数与不定积分

**图谱路径：** 数学分析II / 不定积分 / 不定积分的概念与基本积分公式 / 原函数与不定积分

**教材范围：** 陈纪修等《数学分析》第三版上册，第6章，书页197起、PDF第225页起；本条精确页待核

**习题：** [题目与简解](习题.md#analysis-ii-g004)

**知识内容。** 若区间 $I$ 上 $F'(x)=f(x)$，则 $F$ 是 $f$ 的原函数；同一连通区间上的全部原函数恰为 $F+C$。记 $\int f(x)\,dx=F(x)+C$；不连通定义域的每个分支可有独立常数。例：$\int 2x\,dx=x^2+C$。

#### 基本积分表

**习题：** [题目与简解](习题.md#analysis-ii-g005)

**知识内容。** 基本公式由求导逆推：$\int x^\alpha dx=x^{\alpha+1}/(\alpha+1)+C$（$\alpha\ne-1$），$\int dx/x=\ln|x|+C$，$\int e^x dx=e^x+C$，$\int\cos x\,dx=\sin x+C$，$\int\sin x\,dx=-\cos x+C$。使用幂函数公式先核定义区间。

#### 定积分的问题来源与定义

#### 可积的必要条件

**图谱路径：** 数学分析II / 定积分 / 可积条件 / 可积的必要条件

**教材范围：** 陈纪修等《数学分析》第三版上册，第7章，书页223起、PDF第252页起；本条精确页待核

**习题：** [题目与简解](习题.md#analysis-ii-g019)

**知识内容。** Riemann 可积函数必在闭区间上有界；若函数在某点无界，则不能作为通常的 Riemann 积分。可积不要求处处连续，例如只有有限个跳跃点的有界函数仍可积；因此有界只是必要而非充分条件。

<a id="analysis-ii-g020"></a>
#### 可积的充要条件

**图谱路径：** 数学分析II / 定积分 / 可积条件 / 可积的充要条件

**教材范围：** 陈纪修等《数学分析》第三版上册，第7章，书页223起、PDF第252页起；本条精确页待核

**习题：** [题目与简解](习题.md#analysis-ii-g020)

**知识内容。** 有界函数 $f$ 可积当且仅当对任意 $\varepsilon>0$ 存在分割 $P$，使上、下 Darboux 和之差 $U(P,f)-L(P,f)<\varepsilon$。等价地，其不连续点集具有 Lebesgue 测度零；后一个判据用于识别含可数间断点的例子。

#### 定积分的基本性质

**图谱路径：** 数学分析II / 定积分 / 定积分的性质 / 定积分的基本性质

**教材范围：** 陈纪修等《数学分析》第三版上册，第7章，书页223起、PDF第252页起；本条精确页待核

**习题：** [题目与简解](习题.md#analysis-ii-g023)

**知识内容。** 积分满足线性、区间可加性、保序性与估计 $|\int_a^b f|\le\int_a^b|f|$。若 $m\le f\le M$，则 $m(b-a)\le\int_a^b f\le M(b-a)$。若 $f\ge0$ 且连续并在某点严格正，则积分严格正。

<a id="analysis-ii-g024"></a>
#### 积分中值定理

**图谱路径：** 数学分析II / 定积分 / 定积分的性质 / 积分中值定理

**教材范围：** 陈纪修等《数学分析》第三版上册，第7章，书页223起、PDF第252页起；本条精确页待核

**习题：** [题目与简解](习题.md#analysis-ii-g024)

**知识内容。** 若 $f$ 连续、$g$ 可积且在 $[a,b]$ 不变号，则存在 $\xi\in[a,b]$ 使 $\int_a^b fg=f(\xi)\int_a^b g$。特别令 $g=1$，有 $\int_a^b f=f(\xi)(b-a)$。不变号条件不能随意省去；例如 $x\cdot x$ 中把 $g=x$ 代入会误判。

#### 全微分

**习题：** [题目与简解](习题.md#analysis-ii-g117)

**知识内容。** $f:\mathbb R^n\to\mathbb R^m$ 在 $a$ 可微，指存在唯一线性映射 $A$，使 $f(a+h)=f(a)+Ah+o(\|h\|)$。$A=Df(a)$ 的矩阵即 Jacobian，实值函数的全微分为 $df=\sum_i\partial_i f\,dx_i$。

#### 一阶微分形式不变性
