# 课程资源包（网站分发副本）

本目录是网站的统一课程包目录。一门课一个 `course-<id>/` 文件夹；每门课必须有 `知识节点.xlsx`、`知识点.md`、`习题.md`，正文或习题引用了插图时，按原相对路径附上对应图片。当前 14 门课程均以这个结构接入；同调论仍待来源方修订题目格式。

生成的课程 JSON 和浏览器离线入口在 `../data/`。请修改权威来源中的三份文件后运行 `npm run import:course -- "/完整路径/课程文件夹"`，不要直接编辑生成的 JSON。网页导入使用同一个解析器，但只保存在当前浏览器；开发导入才更新可分发的网站文件。

教材 PDF 不参与知识图谱或题库解析，也不随网站分发；教材名称、书页和 PDF 页码可留在 Markdown 的出处文字中。原始知识数据库仍在用户提供的另一个文件夹内，本目录只是供网站使用的精简副本。旧版网站的 `resources/` 副本已移入 `.preview/legacy-resources-v0.5/`，不进入分发 ZIP。

已接入课程与数据量见[课程接入清单](../docs/课程接入清单.md)。本轮四门课逐文件核对见[导入报告](../reports/course-import-2026-10-11.json)，同调论的来源修订要求见[提示词](../docs/同调论资源包修订提示词.md)。旧[问题清单](../reports/source-package-issues.json)仅为 v0.6 历史记录。
